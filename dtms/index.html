镜像内容管理

仓库与令牌

打开本页会自动从 GitHub 拉取 data/mirrors.json 的最新内容（公开仓库无需令牌即可读取）。 填写 Personal Access Token 后即可提交更新，GitHub Pages 通常 1 分钟内生效；当前域名为 -，任何镜像域名都能使用本页。

GitHub Personal Access Token

建议使用 Fine-grained token，仅勾选本仓库的 Contents: Read and write，并设置较短有效期。 令牌只保存在本机浏览器（localStorage），不会写入仓库。

镜像列表

首页标题下拉框中的全部条目，顺序即显示顺序；关闭「启用」即从列表隐藏（不会删除）。删除按钮移除该条，刷新页面可恢复线上内容。

搜索分发权重

当前激活的搜索引擎，首页搜索时按权重随机分发；权重自动归一化，无需合计为 100，全部停用时按列表顺序兜底。

下拉框标题

显示在镜像列表顶部的标题与右侧提示文字。

提交更新

提交前会自动检查远端是否有新改动，避免覆盖别人的修改。
