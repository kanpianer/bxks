## 项目特性

- **黑白灰极简美学**: 全站严格遵循纯粹的黑、白、灰色调，去除一切多余杂色。
- **LXGW WenKai 霞鹜文楷字体**: 优雅的人文楷体质感，兼顾文学美感与现代屏显易读性。
- **极简图标搜索按钮**: 采用极简前进箭头图标作为提交按钮，无冗余文字。
- **垂直向上滚动提示**: 旧书名从搜索框中央向上淡出，新书名从下方平滑滑入居中。输入内容时自动淡出隐藏提示，清空时自动恢复显示；支持未输入直接搜索当前推荐书目。
- **移动端宽度自适应优化**: 移动端自动将搜索框宽度调整缩减 1/4（保持为 75% 宽），居中且贴合单手操作。
- **立体悬浮精装书籍联动**:
  - 精确还原精装书 3D 结构（圆弧质感书脊、压纹折痕、微米级交叉网纹水印、真实纸张厚度切面）。
  - 在固定安全范围内轻柔呼吸悬浮（float）与底部透视阴影同步伸缩。
  - 与搜索框书名毫秒级同步切换，支持 3D 悬浮与拖拽互动。
- **智能加权多镜像搜索引擎分发**:
  - 分发域名与权重集中在 `data/mirrors.json`，可随时通过 CMS 调整。
  - 权重自动归一化（当前为 `libb.la`、`z-library.website`、`zh.swe101.ru`、`zh.101isfj.ru` 各 25%）。
  - 规范化转换为标准搜索接口 `https://{domain}/s/{query}`。
- **现代前端体验与无障碍**:
  - 中文输入法（IME）防误触提交流程（`isComposing` 与 `keyCode === 229` 双重校验）。
  - 支持系统深浅色模式，配备星空微粒背景。

## 内容管理（CMS）

管理地址为 **`网站域名/dtms`**（例如 <https://bxks.pages.dev/dtms>）。页面为纯静态，不依赖服务器，
任何镜像域名都可直接打开。

### 可维护的内容

| 内容 | 说明 |
| --- | --- |
| 镜像列表 | 下拉框中的全部条目：域名、右侧标签（没墙 / 官方防丢渠道 / 本站镜像等）、启用状态与顺序；可逐条添加、删除、上下移动 |
| 搜索分发权重 | 当前激活的搜索引擎：分发到哪些域名、各自权重、启用状态；同样可增删与排序 |
| 下拉框标题 | 列表顶部的标题与右侧提示文字 |

数据保存在 `data/mirrors.json`，首页在加载时读取它；如果该文件缺失或格式错误，
首页会回退到 `index.html` 中内置的静态列表，不会白屏。

### 打开即同步

打开 `网站域名/dtms` 时会**自动从 GitHub 拉取 `data/mirrors.json` 的最新内容**并在页面中展示，
公开仓库无需填写令牌即可读取，因此：任何域名打开看到的都是线上最新数据；误删一条后刷新页面即可恢复；
若同步失败（断网、限流等），会回退到站内副本并在日志中说明。令牌只在「提交更新」时才需要。

### 提交方式

1. 打开 `网站域名/dtms`，页面会自动同步线上最新内容。
2. 填写 GitHub **Personal Access Token**（建议 Fine-grained，仅勾选本仓库的 `Contents: Read and write`，并设置较短有效期）。
3. 仓库 `owner` / `repo` / `branch` / 数据文件路径默认已由 `dtms/config.json` 提供，可按需修改。
4. 增删改内容后点击「提交更新」，将直接以 commit 方式写入仓库；GitHub Pages 通常 1 分钟内生效。

说明：

- 令牌只保存在本机浏览器（localStorage），不会写入仓库；取消勾选「在本机记住令牌」即可不保存。
- 若记住了过期令牌，读取时会自动改用匿名方式重试，不影响同步。
- 提交前会自动比对远端 sha，若远端已被他人修改会中止提交，避免覆盖；确认无误可勾选「强制覆盖远端」。
- `/dtms` 已在 `robots.txt` 中禁止抓取，页面本身也带有 `noindex`。
